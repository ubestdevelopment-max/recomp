RECOMP APP - how to put it online (free)

Option 1: GitHub Pages (recommended, permanent)
1. github.com -> New repository -> name: recomp -> Public -> Create.
2. "uploading an existing file" -> drag ALL files from this folder (not the folder itself) -> Commit.
3. Settings -> Pages -> Source: Deploy from a branch -> Branch: main, / (root) -> Save.
4. Wait 1-2 minutes. Your app: https://<your-username>.github.io/recomp/

Option 2: Netlify Drop
1. app.netlify.com/drop -> sign up free -> drag this whole folder in.
2. You get an https link right away.

Then on your phone:
1. Open the link in Chrome.
2. Tap "Install" on the Recomp card (or menu -> Install app).
3. Open Recomp from your home screen -> Alerts -> Phone notifications -> Allow.

Updating later: replace index.html in the repo. The app picks up the new version next time you open it online.
